Odoo 16 - Point of Sale

POS Refund User Restriction

Kendalikan proses retur POS dengan memberikan hak refund hanya kepada pengguna yang dipercaya, tanpa mengganggu transaksi penjualan normal.

👤

Izin per Pengguna

Administrator dapat mengaktifkan opsi Boleh Retur POS pada akun pengguna yang memang berwenang.

🔒

Proteksi Berlapis

Pembatasan diterapkan pada antarmuka POS, formulir backend, dan validasi server untuk mencegah proses refund tanpa izin.

🛒

POS Tetap Sederhana

Tombol refund otomatis disembunyikan bagi kasir tanpa hak, sementara transaksi penjualan biasa tetap berjalan seperti sebelumnya.

Cara Menggunakan

1

Buka Pengaturan Pengguna

Masuk ke menu pengguna sebagai administrator.

2

Aktifkan Hak Retur

Pada tab Point of Sale, centang opsi Boleh Retur POS.

3

Mulai Sesi POS

Pengguna berizin dapat melakukan refund dari POS maupun backend.

Perilaku Modul

  • Menyembunyikan tombol refund untuk pengguna tanpa izin.
  • Menolak payload refund yang dikirim tanpa hak akses.
  • Melindungi aksi refund pada pesanan POS di backend.
  • Tidak membatasi transaksi penjualan POS normal.
